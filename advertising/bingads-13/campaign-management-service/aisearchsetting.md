# AISearchSetting Data Object - Campaign Management
Defines AI Max settings for a Search campaign. *AISearchSetting* is the V13 contract name for AI Max. <!-- For an end-to-end setup guide, see [AI Max Campaigns](../guides/ai-max.md). -->

## <a name="remarks"></a>Remarks

AI Max is supported only for Search campaigns and is subject to account eligibility. The
*AISearchEnabled* element is the parent switch. When it is *false*, final URL expansion,
auto-generated text, auto-generated images, and search term matching are all opted out.

*AutoGeneratedTextOptOut* and
[ResponsiveSearchAdsSetting.AutoGeneratedAssetsEnabled](responsivesearchadssetting.md#autogeneratedassetsenabled)
represent opposite forms of the same text-generation setting. If both are supplied,
*AutoGeneratedTextOptOut* takes precedence. Enabling responsive search ad auto-generated assets, or
setting *AutoGeneratedTextOptOut* to *false*, enables AI Max if necessary. Disabling responsive
search ad auto-generated assets opts out of text generation but does not disable AI Max.

Auto-generated images require separate account eligibility. Page feeds and AI Max URL inclusions
also require account eligibility. You can associate at most 20 unique page feed IDs. On update,
omitting *PageFeedIds* or supplying an empty list preserves the current associations.

For AI Max URL inclusion rules, see [BiddableAdGroupCriterion Webpage Usage](biddableadgroupcriterion.md#webpage).
For brand inclusion requirements, see [SharedEntityAssociation](sharedentityassociation.md).

The following AI Max-specific errors can be returned.

|Code|Error|Description|
|---:|---|---|
|6901|AccountNotEnabledForAIMax|The account is not eligible for AI Max.|
|6902|InvalidAIMaxSettings|The parent and child settings are inconsistent, or URL expansion is enabled while auto-generated text is opted out.|
|6903|AccountNotEnabledForAIMaxImage|The account is not eligible for AI Max image generation.|
|6906|AccountNotEnabledForAIMaxUrlInclusion|The account is not eligible for AI Max URL inclusions or page feeds.|

## <a name="elements"></a>Elements

The [AISearchSetting](aisearchsetting.md) object has the following elements: [AISearchEnabled](#aisearchenabled), [AutoGeneratedImageOptOut](#autogeneratedimageoptout), [AutoGeneratedTextOptOut](#autogeneratedtextoptout), [FinalUrlExpansionOptOut](#finalurlexpansionoptout), [PageFeedIds](#pagefeedids), [SearchTermMatchingOptOut](#searchtermmatchingoptout).

|Element|Description|Data Type|
|-----------|---------------|-------------|
|<a name="aisearchenabled"></a>AISearchEnabled|Determines whether AI Max is enabled. If *false*, all child features are opted out.<br/><br/>**Add:** Optional<br/>**Update:** Optional. If set to *false*, all child opt-outs are set to *true*.|**boolean**|
|<a name="autogeneratedimageoptout"></a>AutoGeneratedImageOptOut|Determines whether to opt out of auto-generated images. Set to *false* to enable image generation. Separate account eligibility is required.<br/><br/>**Add:** Optional. The default is *true*.<br/>**Update:** Optional. If omitted, the current value is preserved.|**boolean**|
|<a name="autogeneratedtextoptout"></a>AutoGeneratedTextOptOut|Determines whether to opt out of auto-generated text. This value is synchronized with [ResponsiveSearchAdsSetting.AutoGeneratedAssetsEnabled](responsivesearchadssetting.md#autogeneratedassetsenabled).<br/><br/>**Add:** Optional. The default is *true*.<br/>**Update:** Optional. If omitted, the current value is preserved.|**boolean**|
|<a name="finalurlexpansionoptout"></a>FinalUrlExpansionOptOut|Determines whether to opt out of final URL expansion. Set to *false* to enable expansion. Auto-generated text must also be enabled, and the campaign must use an eligible bid strategy.<br/><br/>**Add:** Optional. The default is *true*.<br/>**Update:** Optional. If omitted, the current value is preserved.|**boolean**|
|<a name="pagefeedids"></a>PageFeedIds|The unique page feed identifiers to associate with AI Max. You can specify at most 20 IDs.<br/><br/>**Add:** Optional<br/>**Update:** Optional. If omitted or empty, the current associations are preserved.|**long** array|
|<a name="searchtermmatchingoptout"></a>SearchTermMatchingOptOut|Determines whether to opt out of search term matching. Set to *false* to enable search term matching. The campaign must use an eligible bid strategy.<br/><br/>**Add:** Optional. The default is *true*.<br/>**Update:** Optional. If omitted, the current value is preserved.|**boolean**|

The [AISearchSetting](aisearchsetting.md) object has [Inherited Elements](#inheritedelements).
