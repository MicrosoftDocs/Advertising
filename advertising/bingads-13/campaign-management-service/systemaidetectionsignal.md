# SystemAIDetectionSignal Value Set - Campaign Management
Defines Microsoft's detection of AI provenance for an asset.

> [!NOTE]
> Not everyone has this feature yet. If you don't, don't worry - it's coming soon!

This value is returned by the system and is read-only. Advertisers cannot set or modify it. It is separate from the advertiser's [AdvertiserAILabel](advertiserailabel.md) declaration. For more information, see [AI transparency](../guides/ai-transparency.md).

## Syntax
```xml
<xs:simpleType name="SystemAIDetectionSignal" xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:annotation>
    <xs:appinfo>
      <ActualType Name="unsignedByte" Namespace="http://www.w3.org/2001/XMLSchema" xmlns="http://schemas.microsoft.com/2003/10/Serialization/" />
    </xs:appinfo>
  </xs:annotation>
  <xs:restriction base="xs:string">
    <xs:enumeration value="NotSupportedForGivenRevision" />
    <xs:enumeration value="MicrosoftAIGenerated" />
    <xs:enumeration value="AISignatureDetected" />
    <xs:enumeration value="NoSignalDetected" />
  </xs:restriction>
</xs:simpleType>
```

## <a name="values"></a>Values

The [SystemAIDetectionSignal](systemaidetectionsignal.md) value set has the following values: [AISignatureDetected](#aisignaturedetected), [MicrosoftAIGenerated](#microsoftaigenerated), [NoSignalDetected](#nosignaldetected), [NotSupportedForGivenRevision](#notsupportedforgivenrevision).

|Value|Description|
|-----------|---------------|
|<a name="aisignaturedetected"></a>AISignatureDetected|An AI-content signature was detected.|
|<a name="microsoftaigenerated"></a>MicrosoftAIGenerated|Microsoft identified the asset as generated by Microsoft AI.|
|<a name="nosignaldetected"></a>NoSignalDetected|No supported AI-content signal was detected. This does not establish that the asset contains no AI-generated content.|
|<a name="notsupportedforgivenrevision"></a>NotSupportedForGivenRevision|The requested API revision does not expose this capability.|
