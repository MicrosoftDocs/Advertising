# AI Max with the Bulk API

Use the Bulk API to configure AI Max settings on Search campaigns, retrieve campaign brand-list
associations, associate page feeds, and manage URL targeting. Campaign settings and page feed IDs
are fields on a [Campaign](../bulk-service/campaign.md) record. URL inclusion targets use the
[Ad Group Url Target](../bulk-service/ad-group-url-target.md) record.

AI Max is available only for eligible accounts and Search campaigns. Page feeds and URL inclusion
targets require separate AI Max URL-inclusion eligibility. For a general overview of the feature,
see [AI Max Campaigns](ai-max.md).

## <a name="campaign-settings"></a>Configure campaign settings

Set the [Campaign Type](../bulk-service/campaign.md#campaigntype) to *Search*. Use the preferred
[AI Search Enabled](../bulk-service/campaign.md#aisearchenabled) column to enable or disable AI Max.
The legacy [AI Max Enabled](../bulk-service/campaign.md#aimaxenabled) column represents the same
parent setting and will be deprecated in the future.

The Campaign record supports the following AI Max settings:

|Bulk column|How to use it|
|---|---|
|[AI Search Enabled](../bulk-service/campaign.md#aisearchenabled)|Set to *true* to enable AI Max. This is the preferred parent-setting column.|
|[Search Term Matching Opt Out](../bulk-service/campaign.md#searchtermmatchingoptout)|Set to *false* to enable AI Max search term matching. An eligible conversion-based or portfolio bid strategy is required.|
|[URL Expansion Opt Out](../bulk-service/campaign.md#urlexpansionoptout)|Set to *false* to enable final URL expansion. Auto-generated text and an eligible conversion-based or portfolio bid strategy are also required.|
|[Auto Generated Text Assets Opt Out](../bulk-service/campaign.md#autogeneratedtextassetsoptout)|Set to *false* to enable generated text assets. This setting is synchronized with RSA auto-generated assets; if both fields conflict, this opt-out field takes precedence.|
|[Auto Generated Image Assets Opt Out](../bulk-service/campaign.md#autogeneratedimageassetsoptout)|Set to *false* to enable generated image assets. Additional account eligibility is required.|
|[Page Feed Ids](../bulk-service/campaign.md#pagefeedids)|Associate up to 20 unique page feed IDs. AI Max URL-inclusion eligibility is required.|

When adding a Search campaign, omitted AI Max child opt-out fields default to *true*. When updating
a campaign, omitted child fields keep their current values. To upload any AI Max child setting or
AI Max page feed IDs, include either *AI Search Enabled* or the legacy *AI Max Enabled* column in
the same Campaign record. If AI Max is disabled, its child features are opted out.

Use an eligible bid strategy before enabling search term matching or final URL expansion. For all
field requirements and update behavior, see the [Campaign record reference](../bulk-service/campaign.md)
and [AISearchSetting](../campaign-management-service/aisearchsetting.md).

## <a name="page-feeds"></a>Associate page feeds

Create and manage page feeds and feed items with the Bulk [Feed](../bulk-service/feed.md) and
[Feed Item](../bulk-service/feed-item.md) records. Then set their IDs in the Campaign record's
[Page Feed Ids](../bulk-service/campaign.md#pagefeedids) field. For the feed schema and upload
steps, see [Page Feeds](page-feeds.md).

For an AI Max Search campaign, you can associate up to 20 unique page feed IDs. The account must
have AI Max URL-inclusion eligibility. In a mixed campaign, AI Max owns the page feed associations
when AI Max URL inclusions are enabled; otherwise, Dynamic Search Ads owns them. See
[Page Feed Ids](../bulk-service/campaign.md#pagefeedids) for mixed-campaign behavior and update rules.

## <a name="url-inclusions"></a>Manage URL inclusion targets

Add an AI Max URL inclusion with an [Ad Group Url Target](../bulk-service/ad-group-url-target.md)
record. The target must belong to a standard Search ad group in an AI Max-enabled Search campaign.
It must have at least one condition and can have up to three. Conditions in a target use AND logic;
multiple targets in the same ad group use OR logic. A URL *Equals* condition must be the only
condition in its target.

URL inclusion targets are biddable and inherit bidding from the parent ad group. URL exclusion
targets aren't supported. A bid, tracking template, custom parameters, and final URL suffix aren't
supported for this record. Conditions can't be updated; delete the target and add a new one to
change its conditions.

The supported conditions and operators are:

|Condition|Supported operator|
|---|---|
|Url|Contains or Equals|
|Category|Equals|
|CustomLabel|Equals|
|PageTitle|Contains|
|PageContent|Contains|

In a mixed campaign, use the [Ad Group Dynamic Search Ad Target](../bulk-service/ad-group-dynamic-search-ad-target.md)
record for *SearchDynamic* ad groups. Standard Search ad groups can use AI Max URL inclusion
targets.

## <a name="brand-lists"></a>Download and manage brand lists

To download brand lists and their campaign associations, include
[DownloadEntity.BrandList](../bulk-service/downloadentity.md#brandlist) and
[DownloadEntity.CampaignBrandListAssociation](../bulk-service/downloadentity.md#campaignbrandlistassociation),
respectively. The association indicates whether a brand list is applied as an inclusion or
exclusion.

Manage campaign-level brand list associations with Campaign Management
[SetSharedEntityAssociations](../campaign-management-service/setsharedentityassociations.md) and
[DeleteSharedEntityAssociations](../campaign-management-service/deletesharedentityassociations.md).
For a brand-list association, set `SharedEntityType` to `BrandList`, `EntityType` to `Campaign`,
and `IsExclusion` to `true` for an exclusion or `false` for an inclusion. For AI Max, changes to
brand inclusions require search term matching to be enabled; brand exclusions are not subject to
that requirement. See [AI Max Campaigns](ai-max.md#brand-lists) for the behavior.

## <a name="campaign-negative-webpages"></a>Manage campaign negative webpages

Use a [Campaign Negative Webpage](../bulk-service/campaign-negative-webpage.md) record to exclude
webpages at the campaign level. For an AI Max Search campaign, AI Max and final URL expansion must
be enabled; set `AISearchSetting.AISearchEnabled` to `true` and
`FinalUrlExpansionOptOut` to `false`.

The record supports up to three URL conditions with `contains` or `equals` operators. The condition,
operator, and value fields can't be updated; delete the record and add a new one to change them.
These campaign-level exclusions are separate from AI Max URL inclusion targets, which use the
[Ad Group Url Target](../bulk-service/ad-group-url-target.md) record.

## <a name="download"></a>Download AI Max data

To download campaign settings, URL inclusion targets, brand lists, brand-list associations, and
campaign negative webpages, request the corresponding *Campaigns*, *AdGroupUrlTargets*, *BrandList*,
*CampaignBrandListAssociation*, and *CampaignNegativeWebpages* [DownloadEntity](../bulk-service/downloadentity.md)
values and include the *EntityData* [DataScope](../bulk-service/datascope.md#entitydata). Full
downloads return current records. Delta downloads include records changed since the last sync.

For general download and upload guidance, see [Bulk Download and Upload](bulk-download-upload.md).
