# AI transparency for assets and product offers

> [!NOTE]
> Not everyone has this feature yet. If you don't, don't worry - it's coming soon!

The Campaign Management API supports AI-content transparency for image and video assets. Advertisers can declare whether an asset contains AI-generated content and request a visible AI watermark where supported. Microsoft returns a separate, read-only signal indicating whether AI-related provenance was detected.

Hotel property feeds also support AI-content declarations for listing images. The feed's supported values and behavior differ from the Campaign Management API, as described in [Work with hotel property feeds](#work-with-hotel-property-feeds).

Microsoft Merchant Center (MMC) supports a separate offer-level declaration for AI-generated or AI-modified content. See [Work with product offers](#work-with-product-offers). The supported values and behavior differ across these interfaces; don't map their enums value-for-value.

## Understand the Campaign Management AI-content properties

### Advertiser AI label

[AdvertiserAILabel](../campaign-management-service/advertiserailabel.md) is the advertiser's declaration about an asset.

|Value|Meaning|
|-----|-------|
|AIWithVisibleWatermark|The asset contains AI-generated content, and you request a visible AI watermark where supported.|
|AIContent|The asset contains AI-generated content; no visible watermark is requested.|
|NoAIContent|The advertiser declares that the asset does not contain AI-generated content.|
|NotSupportedForGivenRevision|The requested API revision does not expose this capability.|

Across all three interfaces, *AIWithVisibleWatermark* requests a visible AI watermark where supported; it doesn't declare that the content already has one. *AIContent* declares AI content without requesting a visible watermark; it doesn't declare that the content has no existing watermark.

You can supply the label when adding or updating supported media. After a label has been set, it cannot be cleared. *NoAIContent* is a declaration, not a way to unset the label.

### System AI detection signal

[SystemAIDetectionSignal](../campaign-management-service/systemaidetectionsignal.md) represents Microsoft's detection of AI provenance for an asset.

|Value|Meaning|
|-----|-------|
|MicrosoftAIGenerated|Microsoft identified the asset as generated by Microsoft AI.|
|AISignatureDetected|An AI-content signature was detected.|
|NoSignalDetected|No supported AI-content signal was detected.|
|NotSupportedForGivenRevision|The requested API revision does not expose this capability.|

This property is read-only. Do not set or modify it in add or update requests. *NoSignalDetected* does not establish that the asset contains no AI-generated content.

## Work with image assets

|Task|Relevant topics|
|----|---------------|
|Add an image with an AI-content declaration.|Use [AddMedia](../campaign-management-service/addmedia.md) with an [Image](../campaign-management-service/image.md). Set the *AdvertiserAILabel* property inherited from [Media](../campaign-management-service/media.md).|
|Update an existing image's declaration.|Use [UpdateMedia](../campaign-management-service/updatemedia.md). Specify the existing image's *Id* and the *AdvertiserAILabel* to update. The operation supports partial success; inspect *PartialErrors* and use each error's zero-based *Index* to identify the failed request item.|
|Retrieve the declaration and detection signal.|Use [GetMediaMetaDataByAccountId](../campaign-management-service/getmediametadatabyaccountid.md) or [GetMediaMetaDataByIds](../campaign-management-service/getmediametadatabyids.md). Both properties can be returned in [MediaMetaData](../campaign-management-service/mediametadata.md).|

## Work with video assets

|Task|Relevant topics|
|----|---------------|
|Add a video with an AI-content declaration.|Use [AddVideos](../campaign-management-service/addvideos.md) and set *AdvertiserAILabel* on the [Video](../campaign-management-service/video.md) object.|
|Update an existing video's declaration.|Use [UpdateVideos](../campaign-management-service/updatevideos.md) to update *AdvertiserAILabel*.|
|Retrieve the declaration and detection signal.|Use [GetVideosByIds](../campaign-management-service/getvideosbyids.md). Both properties can be returned on the [Video](../campaign-management-service/video.md) object.|

## Work with hotel property feeds

Use the optional `AdvertiserAILabel` string element in a listing's `content` element to declare whether the hotel's images contain AI-generated content. The label applies to all of the listing's `image` elements. Specify only one `AdvertiserAILabel` element per listing.

|Value|Meaning|
|-----|-------|
|AIWithVisibleWatermark|The images contain AI-generated content, and you request a visible AI watermark where supported.|
|AIContent|The images contain AI-generated content; no visible watermark is requested.|
|NoAIContent|The images don't contain AI-generated content.|

If you omit the element or leave it empty, the hotel's AI content label isn't set. Unsupported values are ignored, and the label isn't set.

For the element definition and feed structure, see the [Content Type section of the Property feed reference](../../hotel-feed/reference.md#contenttype).

## Work with product offers

Use the optional `advertiserAILabel` string property on the MMC Content API [Product](../../shopping-content/products-resource.md#product) object to declare whether a specific offer contains AI-generated or AI-modified content. This is an advertiser declaration, not a system-generated detection signal.

|Value|Meaning|
|-----|-------|
|AIWithVisibleWatermark|The offer contains AI-generated or AI-modified content, and you request a visible AI watermark where supported.|
|AIContent|The offer contains AI-generated or AI-modified content; no visible watermark is requested.|
|NoAIContent|The advertiser declares that the offer doesn't contain AI-generated or AI-modified content.|

Omit the attribute or use `null` when no declaration is provided.

|Input|Attribute name|
|-----|--------------|
|Text or CSV feed|`advertiser_ai_label`|
|XML feed|`<advertiser_ai_label>`|
|MMC Content API JSON|`advertiserAILabel`|

Processing requires the `OfferAdvertiserAILabel` store pilot to be enabled. Otherwise, MMC clears the value to `null`. With the pilot enabled, MMC stores supported declarations supplied through primary and legacy online feeds, XML feeds, and Content API insert, update, and batch operations. Content API read operations also support the attribute.

Unlike Campaign Management asset labels, an MMC offer declaration can be cleared. An omitted or empty feed attribute, or an omitted or `null` Content API property, clears the declaration to `null`. Unrecognized feed values produce a validation warning and don't propagate; the declaration is set to `null`. Inventory feeds, local feeds, and automatic price or availability updates don't independently set the value.

For the full contract and feed and API examples, see [Offer AI-content declarations in the Products resource](../../shopping-content/products-resource.md#offer-ai-content-declarations). Content API updates replace the existing offer, so include all required offer fields when changing or clearing the label.

## Handle Campaign Management validation errors

The following [operation error codes](operation-error-codes.md) apply to Campaign Management AI-content operations, not hotel property feeds or MMC product offers.

|Code|Symbolic error code|Meaning|
|----|-------------------|-------|
|[6247](operation-error-codes.md#6247)|CampaignServiceInvalidAdvertiserAILabel|The advertiser AI label is invalid.|
|[6248](operation-error-codes.md#6248)|CampaignServiceAdvertiserAILabelCannotBeUnset|The advertiser AI label cannot be unset after it has been specified.|
|[6249](operation-error-codes.md#6249)|CampaignServiceAdvertiserAILabelAssetTypeNotSupported|The advertiser AI label is not supported for the specified asset type.|
|[6250](operation-error-codes.md#6250)|CampaignServiceSystemAIDetectionSignalReadOnly|The system AI detection signal is read-only.|

For general error-handling guidance, see [Handling Service Errors and Exceptions](handle-service-errors-exceptions.md).
